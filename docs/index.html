核心功能

抓得全、挑得快、存得对

不折腾脚本和插件面板，点一下，这一页的图就是你的。

整页图片一次抓全

普通图片、srcset 多倍图、懒加载属性、CSS 背景图都在范围内，详情长图也不会漏。

自动还原原图

识别并去掉 CDN 的缩略后缀，能拿原图就不拿缩略图，保存下来就是清晰度最高的那一份。

去重与降噪

真正的 PNG 输出

用 canvas 重新编码，不是改后缀；批量并发下载，带进度条，失败的单张可以重试。

全部在本地完成

不登录、不上传、不收集。图片只在你自己的浏览器里处理，关掉页面就结束。

使用流程

三步，从详情页到本地 PNG

不需要懂代码，也不需要复制链接到别的地方粘贴。

  1. 1

    打开商品详情页

    淘宝、天猫、京东、拼多多商家版的商品页面都支持。

  2. 2

    点右下角「获取图片」

    扩展会自动滚动页面触发懒加载，把这一页的图收集起来，然后打开结果页。

  3. 3

    勾选后下载 PNG

    在结果页挑图，批量保存到「下载 / 电商图片」文件夹里。

安装

四步装进 Chrome

目前通过 GitHub 下载安装，暂未上架 Chrome 应用商店。

  1. 1

    下载项目

    打开 GitHub 仓库，点绿色 Code → Download ZIP。

  2. 2

    解压到一个固定目录

    解压后确认文件夹里能直接看到 manifest.json，不要再多套一层文件夹。

  3. 3

    打开扩展管理页

    地址栏输入 chrome://extensions，打开右上角的「开发者模式」。

  4. 4

    加载已解压的扩展程序

    点左上角「加载已解压的扩展程序」，选择刚才那个含 manifest.json 的文件夹。

装好后建议点工具栏的拼图图标，把它固定出来。之后打开商品详情页，右下角就会出现「获取图片」。

常见问题

你可能想问

会不会收集我的数据？

不会。扩展没有服务端，图片在你的浏览器里完成抓取、转换和下载，不登录、不上传、不统计。

下载下来的是真的 PNG 吗？

是。图片会先被解码，再用 canvas 重新编码成 PNG，文件头就是 PNG 格式，不是把 .webp 改个后缀。

为什么有些图片没抓全？

常见原因是图片还没加载。先在详情页慢慢滚到底再点按钮；另外跨域 iframe 里的图片、需要登录态才返回的大图，也可能抓不到。

下载的图保存在哪？

默认在浏览器的下载目录下，按「电商图片 / 站点-商品标题 / 001.png」整理好，同一批不会互相覆盖。

需要登录淘宝或京东账号吗？

用的是你浏览器里已有的登录状态，扩展本身不读取、不保存任何账号信息。

手机上能用吗？收费吗？

仅支持桌面版 Chrome。完全免费，也没有会员或次数限制。
